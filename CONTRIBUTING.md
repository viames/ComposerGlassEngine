# Contributing

Thank you for helping improve ComposerGlass Engine. Compatibility claims need a
reproducible fixture or a link to public Composer documentation.

## Before opening a pull request

1. Add focused tests for behavior changes.
2. Run `swift test` from the package root.
3. Document compatibility differences from Composer.
4. Avoid adding runtime dependencies or process execution.
5. Do not include private manifests, credentials, or package source code.

## Lockfile changes

Treat every format-only `composer.lock` diff as a regression. Changes to
parsing, generation, repository metadata mapping, or JSON writing must compare
the complete generated bytes with official Composer output. Decoded JSON
equality is not sufficient. See the normative contract in
[COMPATIBILITY.md](COMPATIBILITY.md).

## Composer baseline changes

Follow [COMPOSER-UPSTREAM.md](COMPOSER-UPSTREAM.md) and update the Swift
reference, machine-readable JSON manifest, compatibility documentation,
fixtures, and changelog together.
